# Условия использования KRYLAN

_Обновлено: 9 июня 2026_

CleanMac («Программа») — часть экосистемы **KRYLAN**.
Создатель: **Кырлан Александр Сергеевич**.

## 1. Лицензия
Программа распространяется по лицензии [MIT](LICENSE): свободно использовать,
копировать, изменять и распространять при сохранении уведомления об авторстве.

## 2. Отказ от гарантий
Программа предоставляется «как есть», без каких-либо гарантий. Автор не несёт
ответственности за возможную потерю данных. Все операции удаления переносят
файлы в **Корзину** (обратимо); безвозвратно удаляет только явная команда
«Очистить Корзину», подтверждаемая пользователем.

## 3. Безопасность
- Системные и пользовательские корневые папки защищены от удаления.
- Кэш браузера очищается только когда браузер закрыт.
- Программа не собирает и не передаёт персональные данные (см. [PRIVACY.md](PRIVACY.md)).
  Единственное сетевое соединение — проверка версии на GitHub.

## 4. Распространение
Программа раздаётся как `.dmg` и через Homebrew, вне Mac App Store
(ограничения песочницы).

**Сборка не нотаризована в Apple** и подписана только ad-hoc-подписью: у автора
нет платной учётной записи Apple Developer. Практическое следствие: скачанный
вручную `.dmg` macOS при первом запуске заблокирует сообщением «Apple не удалось
подтвердить, что файл не содержит вредоносного ПО». Как это снять — описано в
[README](README.md#загрузка). Через Homebrew метка карантина снимается сама.

Используя Программу, вы соглашаетесь с этими условиями.
