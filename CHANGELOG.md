# Changelog

Все заметные изменения проекта документируются здесь.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект следует [семантическому версионированию](https://semver.org/lang/ru/).

> Версии `vX.Y.Z` относятся к флагману **CleanMac (macOS)**. Кросс-платформенные приложения
> KRYLAN (Desktop, iOS, Android) имеют собственные версии и отмечены в записях соответствующей даты.

## [2.42.2] — 2026-06-28
### Безопасность — защита путей удаления (аудит опасных операций)
- [HIGH] `is_protected` теперь отвергает пустые/относительные пути — `to_trash`/`shred`
  не могут затронуть текущий каталог.
- [MEDIUM] Desktop: добавлены `is_protected`/`safe_trash` (защита HOME и системных
  папок); все точки удаления переведены на безопасную обёртку.
- Подтверждено: `shell=True` нигде нет, всё «в Корзину» обратимо, симлинки не
  раскрываются. +8 тестов (CleanMac 68, Desktop 81).

## [2.42.1] — 2026-06-28
### Исправления (баг-хант по всем платформам)
- **macOS/Desktop:** [critical] результат кнопки «Ускорить» больше не теряется
  (слался на вкладку без рендера); битые симлинки теперь действительно удаляются
  (`lexists`); убрано дублирование лога оптимизатора; нет краша при отсутствии
  планировщика (cron/launchd/schtasks обёрнуты).
- **Windows:** скрыты всплывающие консольные окна subprocess; `wmic` → PowerShell;
  defrag/TRIM по правам администратора.
- **iOS/macOS:** тяжёлые сканы фото/контактов/кэша вынесены с главного потока
  (больше не морозят UI).
- **Android:** запросы MediaStore/IO вынесены в фон (устранён ANR/jank).
- Тесты: CleanMac 64, Desktop 77.

## [2.42.0] — 2026-06-27
### Главное — волшебная кнопка ✨ «Оптимизировать» (один клик, без уточнений)
- Один клик прогоняет ВСЕ безопасные функции ускорения и сам определяет ОС и тип диска;
  неприменимое честно пропускается с причиной (прозрачная сводка «Выполнено / Пропущено»).
- **Обслуживание диска по типу носителя:** SSD→TRIM (`defrag /L` · `fstrim`), HDD→дефраг
  (`defrag /O`), macOS→TRIM авто. SSD НИКОГДА не дефрагментируется.
- Desktop: + сброс DNS, кэш миниатюр, пакетные кэши (brew/apt + journal), разгрузка памяти —
  всё по ОС с graceful-пропуском без sudo-промптов.
- macOS: + brew cleanup, перестройка Launch Services, сброс кэша Dock.
- **Фирменный анимированный глобус** на дашборде всех платформ.
- iOS: swipe-разбор фото, Live Photos, неполные контакты, разбор хранилища, онбординг.
- Android: умные подсказки, корзина/undo (createTrashRequest), неиспользуемые приложения.
- Полная EN-локализация Desktop; обновлены README/лендинг; +тесты (CleanMac 63, Desktop 60).
- Принцип неизменен: только безопасное — без реестра, SSD-дефрага, отключения служб; всё обратимо.

## [2.28.0] — 2026-06-24
### Исправлено (CleanMac)
- **Скорость интернета теперь показывается всегда.** Раньше при отсутствии `psutil`
  в .app-бандле сеть зависала на нуле. Добавлен резервный замер через `netstat -ib`
  (встроен в macOS) + `psutil` прописан в hiddenimports PyInstaller. Также исправлена
  рассинхронизация: константа `VERSION` в коде отставала от файла `VERSION`.

### Добавлено (экосистема — скорость интернета на всех устройствах)
- **iOS / macOS (KRYLAN Swift):** живой замер ↓/↑ через `getifaddrs`/`if_data`
  (работает в песочнице iOS) + **спарклайн-график** ↓/↑ на дашборде (Sparkline.swift).
- **Android (KRYLAN):** замер через `TrafficStats` (без разрешений) + **спарклайн-график**
  на Canvas, карточка «Интернет» на дашборде.
- **Windows / Linux (KRYLAN Desktop):** скорость сети через `psutil` — подтверждено.

### Инфраструктура и сторы
- **Автопилот (mac-optimizer):** фоновый страж и `ctl.sh disk` теперь учитывают
  **скрытую системную корзину тома** — предупреждают о «невидимом» мусоре и чистят его
  (авто-очистка по флагу `empty_trash.on`).
- **CI:** исправлен баг сборки macOS-DMG в release.yml (`--exclude-module psutil` —
  иначе universal2 падал); добавлен `enable-ci.sh` для включения Win/Linux-сборок.
- **Сторы:** в `store/listing.md` — тексты «Что нового» и готовые ответы на анкеты
  App Privacy (Apple) / Data Safety (Google): данные не собираются.

### Добавлено (CleanMac)
- **Глубокая очистка Корзины** — инструмент «Корзина» теперь видит не только `~/.Trash`,
  но и **системную корзину тома** (`/System/Volumes/Data/.Trashes/UID`) и корзины внешних
  томов. Это главный скрытый пожиратель места: обычная Корзина Finder может выглядеть пустой,
  а там тихо копятся десятки гигабайт (реальный кейс — освобождено ~95 ГБ). Показывает разбивку
  по каждой корзине и предупреждает, сколько спрятано в системной.
- **Категория «Образ VM-песочницы Claude» (vm_bundles)** в разделе «Очистка» — базовый образ
  виртуалки Claude Code (до ~11 ГБ), пересоздаётся при следующем запуске VM-режима.

## [2.2.0] — 2026-06-07
### Добавлено (по мотивам CleanMyMac / DaisyDisk / OnyX)
- **✨ Умная очистка (Smart Scan)** — один проход по всем безопасным категориям
  и очистка всего в один клик.
- **🗺 Карта диска** — визуальные бары крупнейших папок, клик → Finder.
- **🩺 Обслуживание** — освободить память (purge), сбросить кэш DNS,
  переиндексировать Spotlight, очистить кэш шрифтов и Quick Look,
  перестроить Launch Services.
- **Очистка для разработчика** — Xcode (DerivedData / DeviceSupport / Archives /
  Simulator) и кэши пакетных менеджеров (npm / pip / yarn / brew).

## [2.0.0] — 2026-06-07
### Добавлено
- **Дашборд** со «стеклянным» оформлением: матовые карточки, плавные анимации.

  (вкл/выкл, журнал, «Оптимизировать сейчас»).

- Каркас **Pro**: лицензия + кнопка покупки (внешняя ссылка).
- Фирменная иконка `.icns`.
