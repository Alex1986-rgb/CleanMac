# Changelog

Все заметные изменения проекта документируются здесь.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект следует [семантическому версионированию](https://semver.org/lang/ru/).

## [2.3.0] — 2026-06-07
### Добавлено
- **🔒 Приватность** — очистка следов: списки недавних файлов, сохранённые
  состояния окон, история и cookies Safari / Chrome / Edge (браузер должен быть
  закрыт). Всё в Корзину.
- **🛡 Защита** — эвристический сканер известного рекламного/нежелательного ПО
  в LaunchAgents / LaunchDaemons и папках приложений; удаление в Корзину.
  Не заменяет антивирус.

## [2.2.0] — 2026-06-07
### Добавлено (по мотивам CleanMyMac / DaisyDisk / OnyX)
- **✨ Умная очистка (Smart Scan)** — один проход по всем безопасным категориям
  и очистка всего в один клик.
- **🗺 Карта диска** — визуальные бары крупнейших папок, клик → Finder.
- **🩺 Обслуживание** — освободить память (purge), сбросить кэш DNS,
  переиндексировать Spotlight, очистить кэш шрифтов и Quick Look,
  перестроить Launch Services.
- **Очистка для разработчика** — Xcode (DerivedData / DeviceSupport / Archives /
  Simulator) и кэши пакетных менеджеров (npm / pip / yarn / brew).

## [2.1.0] — 2026-06-07
### Добавлено
- **Интерактивные инструменты**: списки с галочками, удаление выбранного в Корзину.
  - Крупные файлы и Дубликаты — отметить и удалить прямо из списка (у дубликатов
    лишние копии отмечаются автоматически).
  - Автозагрузка — тумблеры «Включить/Выключить» для LaunchAgents.
  - Новый **Деинсталлятор**: удаляет приложение вместе с его кэшами и настройками.
- Документы для публикации: `PRIVACY.md`, `SUPPORT.md`, `DISTRIBUTION.md`.

## [2.0.0] — 2026-06-07
### Добавлено
- **Дашборд** со «стеклянным» оформлением: матовые карточки, плавные анимации.
- Диаграммы: кольца Health/CPU/ОЗУ/SWAP/Диск, пончик состава памяти,
  пончик диска, график нагрузки CPU/ОЗУ за минуту.
- Виджет **батареи**: заряд, время, циклы, ёмкость (здоровье), состояние.
- Живой список активных процессов с барами CPU и расходом ОЗУ.
- **Автопилот** — управление фоновым стражем прямо из приложения
  (вкл/выкл, журнал, «Оптимизировать сейчас»).
- **Проверка обновлений** через GitHub (файл `VERSION`).
- Каркас **Pro**: лицензия + кнопка покупки (внешняя ссылка).
- Фирменная иконка `.icns`.

## [1.0.0] — 2026-06-07
### Добавлено
- Базовый GUI-чистильщик: категории кэшей/логов, «Анализ»/«Очистить» в Корзину.
- Инструменты: автозагрузка, крупные файлы, дубликаты, закрытие браузеров,
  очистка Корзины.
