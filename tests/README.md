# 🧪 Тесты KRYLAN CleanMac

Юнит-тесты безопасных функций (без GUI). Внешних зависимостей нет.

## Запуск

```bash
python3 tests/test_cleanmac.py
```

Годится любой Python 3.9+ с tkinter, включая системный `/usr/bin/python3` из
Command Line Tools. Раньше здесь был прибитый гвоздями путь
`/Library/Frameworks/Python.framework/Versions/3.12/bin/python3` — этого Python
на машине может не быть, и инструкция просто не работала.

## Покрытие

**Безопасность удаления** — то, что важнее всего в чистильщике:
- `is_protected()` / `to_trash()` — защита системных и корневых папок
- `leftover_match()` — точное совпадение хвостов приложения при деинсталляции
- сканеры (`scan_dev_junk`, `scan_big_old`, …) — пропуск симлинков

**Разбор вывода системных команд** — `parse_top_cpu`, `parse_memory_pressure`,
`parse_vm_stat`, `parse_pmset_batt`, `parse_ps_procs`, `parse_swapusage`.
Проверяются на настоящих строках вывода. Место коварное: при сбое разбора
функция возвращает правдоподобный ноль, а ноль в метрике выглядит как здоровая
система — так дважды прошли незамеченными «swap 0» при раздутом свопе и «пика
нет» на захлёбывающемся маке.

**Автопилот** — пороги пика, проверка простоя перед закрытием браузеров,
разбор журнала для сводки, комплектность установщика и полнота `zap` в каске.

**Интерфейс** — покрытие словаря переводов (новая строка без перевода валит
тест), состав семейств инструментов, отрисовка пончиков памяти и диска
(проверяется по объектам холста; пропускается там, где Tk недоступен).

**Консистентность выпуска** — версия в `CleanMac.py` совпадает с файлом
`VERSION`, бейджем README и записью в `CHANGELOG.md`; вендорная копия
`krylan_core.py` не разошлась с основной.

## CI

`.github/workflows/ci.yml` гоняет эти тесты на системном Python 3.9 и на 3.12,
плюс `pyflakes`, `bash -n` по скриптам, `swiftc -typecheck` по `krylan-swift`
и сверку версий.
