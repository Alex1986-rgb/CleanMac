## ⚠️ Важно про категорию «чистильщик»
- **App Store (iOS/macOS):** системные чистильщики **отклоняются** (песочница).
  На App Store можно подать только **KRYLAN для iPhone** в урезанном виде:
  фото-дубликаты, контакты, анализ хранилища (без доступа к чужим данным).
  Полный CleanMac/Desktop — **только прямой раздачей** (DMG/Homebrew/.exe).
- **Google Play:** запрещает «фейк-бустеры» и приложения, требующие опасных
  разрешений. KRYLAN для Android подаётся как менеджер хранилища/медиа.

## App Store Connect — KRYLAN (iOS)
- **Название:** KRYLAN
- **Подзаголовок:** Чистка и ускорение устройства
- **Категория:** Утилиты
- **Возраст:** 4+
- **Ключевые слова:** оптимизация, очистка, хранилище, дубликаты, фото, ускорение, монитор, память
- **Описание:**
  > KRYLAN помогает держать iPhone в порядке: находит дубликаты фотографий и
  > контактов, показывает, что занимает память, и даёт советы по оптимизации.
  > Быстро, красиво, безопасно. «Дай устройству крылья».
- **Privacy:** не собираем данные (см. PRIVACY.md). Доступ к Фото/Контактам —
  только локально, по запросу.
- **Нужно для подачи:** Apple Developer Program ($99/год), скриншоты 6.7"/6.1"/5.5",
  иконка 1024×1024 (есть: icon_1024.png), сборка из Xcode (krylan-swift).

## Google Play Console — KRYLAN (Android)
- **Название:** KRYLAN — оптимизация
- **Краткое описание (80):** Монитор хранилища и памяти, очистка кэша, поиск дублей.
- **Полное описание:** аналог iOS-текста, без обещаний «ускорить в N раз».
- **Категория:** Инструменты
- **Контент:** для всех (PEGI 3).
- **Нужно для подачи:** Google Play Console ($25 разово), AAB-сборка из Android Studio
  (krylan-android), скриншоты телефона/планшета, иконка 512×512, баннер 1024×500
  (можно из docs/og.png), политика конфиденциальности (PRIVACY.md → на сайт).

## App Privacy (Apple) / Data Safety (Google) — ответы на анкеты
KRYLAN **не собирает и не передаёт** никаких данных. Заполнять так:
- **Сбор данных:** Нет (No data collected).
- **Аналитика/трекинг:** Нет. Сторонних SDK нет.
- **Доступы и зачем (только локально, по запросу пользователя):**
  - iOS: Фото (`NSPhotoLibraryUsageDescription`) — поиск дубликатов; Контакты
    (`NSContactsUsageDescription`) — поиск дублей. Данные **не покидают устройство**.
  - Android: `READ_MEDIA_*` (Android 13+) / `READ_EXTERNAL_STORAGE` — анализ медиа.
    Сеть-метрики через `TrafficStats` — **без разрешений**, только агрегаты.
- **Аккаунт/вход:** не требуется.
- **Ссылка на политику:** PRIVACY.md → https://alex1986-rgb.github.io/CleanMac/

## Чек-лист подачи (делаешь ты)
1. Apple Developer Program / Google Play Console — регистрация и оплата.
2. Собрать релизные сборки (Xcode Archive / Android Studio → AAB).
3. Загрузить скриншоты, описания, иконки, политику.
4. Заполнить App Privacy / Data Safety по ответам выше (всё «Нет»).
5. Отправить на ревью. Для desktop — раздавать DMG/.exe напрямую (стор не нужен).
