# 🪽 KRYLAN Desktop — Windows · macOS · Linux

**Дай устройству крылья.** Кросс-платформенный оптимизатор на Python/Tkinter:
живой мониторинг CPU/ОЗУ/диск/батарея/сеть и **безопасная** очистка кэшей
(всё удаляется в системную Корзину через `send2trash`). Один код для всех компьютеров.

Версия: **1.11.0** · Создатель: **Кырлан Александр Сергеевич**.

> Принцип «только безопасное»: KRYLAN не трогает системные файлы и не «бустит»
> память агрессивно. Очистка идёт по понятным целям ОС, удаление — в Корзину,
> то есть всегда обратимо.

## Запуск (любая ОС)
```bash
pip install -r requirements.txt
python krylan.py
```
Нужен **Python 3.9+** (на Windows — с python.org, отметьте «Add to PATH»).
Зависимости: `psutil`, `Send2Trash`, `Pillow` (см. `requirements.txt`).

## Что внутри

### Дашборд
- Кольца **CPU / ОЗУ / Диск / Батарея** (psutil) с цветовым семафором нагрузки.
- Анимированный **глобус** (бренд) и сводка по ОС / диску / памяти.
- Скорость сети **↓/↑**.

### Очистка и ускорение
- **Сканер** — что можно безопасно убрать прямо сейчас.
- **«Ускорить»** (Boost) — быстрый прогон безопасных действий.
- **Очистка кэшей по ОС** (удаление в Корзину):
  - Windows: `%TEMP%`, кэш Chrome/Edge, временные файлы Explorer;
  - macOS: `~/Library/Caches`, `~/Library/Logs`;
  - Linux: `~/.cache`, эскизы.
- **Процессы** — диспетчер задач: топ по памяти/CPU и завершение процесса.

### Инструменты
- ⚙️ **Автозагрузка** — что стартует с системой (реестр Windows / LaunchAgents / autostart).
- 👯 **Дубликаты** — точные копии по размеру **+ MD5**.
- 🖼 **Похожие изображения** — near-duplicate по **perceptual hash (dHash)** + расстояние Хэмминга.
- 📦 **Крупные файлы** — самые тяжёлые объекты в пользовательских каталогах.
- 🗺 **Карта диска** — распределение занятого места.
- 🧳 **Деинсталлятор** — установленные приложения.
- 📂 **Пустые папки** — каталоги без файлов на всех уровнях.
- 🧩 **Битые / пустые файлы** — нулевые файлы и битые символические ссылки.
- 📈 **«Что выросло»** — снимок размеров и diff между прогонами.
- 🔒 **Приватность** — следы (история, недавние и т.п.).
- 🩺 **Диск / SMART** — здоровье диска (`diskutil` / `wmic` / `smartctl`).
- 🔄 **Software Updater** — устаревшие приложения через нативный менеджер
  пакетов: **brew** (macOS), **winget** (Windows), **apt** (Linux).
- 📄 **Health Report** — выгрузка состояния и кандидатов на очистку в **HTML**.

### Прочее
- 🎯 **Режим фокуса** — приостановка фоновых процессов-кандидатов
  (с защитным blacklist), возобновление всех одной кнопкой.
- ⏰ **Планировщик** — регулярная фоновая очистка (launchd / crontab / schtasks).
- 🌐 **RU / EN** — переключение языка интерфейса.

## Сборка standalone (PyInstaller)

`krylan_core.py` лежит рядом и подхватывается автоматически — сборка самодостаточна.

### Windows (.exe)
```bat
pip install -r requirements.txt pyinstaller
pyinstaller --onefile --windowed --name KRYLAN --icon krylan.ico krylan.py
:: результат: dist\KRYLAN.exe — запускается на любом Windows без Python
```
> Иконка `krylan.ico` уже в комплекте.
> Без подписи Windows SmartScreen покажет «Запустить всё равно» (Подробнее → Выполнить).

### macOS (.app)
```bash
pyinstaller --onefile --windowed --name KRYLAN --icon ../CleanMac.icns krylan.py
```

### Linux
```bash
pyinstaller --onefile --name krylan krylan.py   # ./dist/krylan
```

## Тесты
```bash
python -m unittest test_krylan -v
```
Покрыты: форматирование размеров, пороги цвета, пустые/битые файлы, дубликаты,
старые загрузки, growth-отчёт, советы по диску, цели очистки/приватности,
парсеры Software Updater (brew/apt/winget), HTML-отчёт, кандидаты режима фокуса.
