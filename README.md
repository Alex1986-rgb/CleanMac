# 🪽 KRYLAN · CleanMac

### «Дай устройству крылья»

**Красивый оптимизатор со «стеклянным» интерфейсом и фирменным анимированным глобусом.**
HUD-дашборд с кольцами-гейджами, Автопилот, безопасная очистка, разбор медиа —
мощнее CleanMyMac, DaisyDisk и CCleaner, но **бесплатно** и с открытым кодом.

**Экосистема KRYLAN:** macOS · Windows · Linux · iPhone/iPad · Android — **все платформы доступны**.
**Создатель:** Кырлан Александр Сергеевич.

> **Только безопасное.** Без чистки реестра «для скорости», без дефрага SSD, без fake-booster
> и страшилок вроде «ускорим в 10 раз». Любое удаление — обратимо (Корзина / «Недавно удалённые» / undo).
> Честные цифры в ГБ. Системное под защитой — решаешь ты.

## Возможности по платформам

Везде одна ДНК: **анимированный неон-глобус** (вращающаяся планета) на HUD-дашборде,
«стеклянный» интерфейс, живые метрики и **Автопилот** в фоне.
Группировка внутри платформы: **Дашборд · Автопилот/Очистка · Разбор медиа · Приватность · Инструменты**.

### 🍎 macOS · CleanMac 2.53.0
- **Дашборд** — HUD с глобусом и кольцами-гейджами Health / CPU / ОЗУ / SWAP / Диск,
  пончики памяти и диска, тренды, живой график интернета ↓/↑, батарея, процессы.
- **Автопилот / Очистка** — **Smart Care в 1 клик** (кэши и логи → Корзина, снимки APFS,
  сброс Quick Look, разгрузка памяти); **Автопилот** — фоновый страж памяти;
  умная очистка и очистка по категориям (всё в Корзину, обратимо).
- **Разбор медиа** — дубликаты, похожие фото, вложения Почты (Mail.app), сжатие (VACUUM) баз браузеров.
- **Приватность** — следы браузеров (история, cookies), недавние файлы, состояния окон;
  защита + **adware-скан LaunchAgents** (эвристика по точкам автозапуска).

## Почему KRYLAN безопаснее конкурентов

| | Агрессивные конкуренты | KRYLAN |
|---|---|---|
| Чистка реестра «для скорости» | CCleaner, BoostSpeed, Glary | ❌ никогда (ломает Windows) |
| Дефрагментация SSD | часть «бустеров» | ❌ никогда (изнашивает накопитель) |
| Fake-booster / «RAM boost» | Boost Cleaner, 1Tap | ❌ нет — только реальная разгрузка |
| Страшилки «storage full!» | многие мобильные | ❌ честные локальные уведомления |
| Обратимость удаления | не всегда | ✅ Корзина / «Недавно удалённые» / undo |
| Честные цифры | часто «×10» | ✅ реальные ГБ, превью до очистки |

**С кем сравниваем:** CleanMyMac / DaisyDisk (mac) · CCleaner / BoostSpeed / BleachBit / Stacer (desktop) ·
Gemini / Smart Cleaner (iOS) · SD Maid / Files by Google (Android).

## ✨ Оптимизировать — умная кнопка для любого устройства

Одна кнопка **✨ «Оптимизировать»** делает **РАЗНОЕ** на разных устройствах.
KRYLAN сам определяет **ОС** (Windows / macOS / Linux) и **тип диска** (SSD или HDD)
и подбирает только те операции, которые на этом железе **безопасны и полезны**.
Дефрагментация SSD не просто бесполезна — она **изнашивает накопитель**,
поэтому KRYLAN её **никогда** не делает. «Дай устройству крылья» — но без вреда. 🪽

| Функция | 🪟 Windows | 🍎 macOS | 🐧 Linux | Почему адаптивно |
|---|:---|:---|:---|---|
| Кэши / логи / temp → Корзина | ✅ | ✅ | ✅ | Освобождает место обратимо на всех ОС |
| Кэш миниатюр | ✅ `thumbcache` | ✅ Quick Look | ✅ `~/.cache/thumbnails` | У каждой ОС своё хранилище превью |
| Сброс DNS | ✅ `flushdns` | ✅ `dscacheutil` | ✅ `resolvectl` | Разные службы резолвинга в каждой ОС |
| **TRIM (обслуживание SSD)** | ✅ `defrag /L` | ✅ авто системой | ✅ `fstrim` | Поддерживает скорость SSD; на mac уже делает сама система |
| **Дефрагментация (ТОЛЬКО HDD)** | ✅ `defrag /O` | — не нужна (APFS) | — не нужна (ext4) | Нужна лишь магнитным дискам; совр. ФС не фрагментируются |
| **SSD-дефраг** | ❌ никогда | ❌ никогда | ❌ никогда | Вредно — изнашивает накопитель |
| Пакетные кэши | — | ✅ `brew cleanup` | ✅ `apt clean` + journal | Чистится только там, где есть пакетный менеджер |
| Разгрузка памяти | — (нет безопасного userland) | ✅ `purge` | ✅ `sync` | На Windows нет безопасной userland-команды |
| Пустые папки · битые файлы · остатки удалённых программ | ✅ | ✅ | ✅ | Универсальная уборка для всех ОС |

**Дополнительно только на macOS:** удаление снимков APFS, перестройка Launch Services, сброс Dock.

- Команды, требующие **админ/root**, KRYLAN пытается выполнить автоматически.
  При отказе в правах — операция **пропускается с пометкой**, без запроса пароля.
- После прохода приложение само показывает **«Выполнено»** и **«Пропущено на этом устройстве»**.

> **Только безопасное.** Кнопка не трогает реестр, не делает SSD-дефраг, не отключает службы
> и не чистит Корзину автоматически. Пользовательские данные (дубли, крупные и старые файлы)
> кнопка **только показывает** — разбираете их вы вручную.

## Загрузка

Все сборки — на странице [Releases](https://github.com/Alex1986-rgb/CleanMac/releases/latest).

| Платформа | Файл / способ |
|---|---|
| 🍎 **macOS** | [`CleanMac.dmg`](https://github.com/Alex1986-rgb/CleanMac/releases/latest/download/CleanMac.dmg) или Homebrew (см. ниже) |
| 🐧 **Linux** | [`krylan-linux-x86_64`](https://github.com/Alex1986-rgb/CleanMac/releases/latest/download/krylan-linux-x86_64) |
| 🪟 **Windows** | `KRYLAN-Windows.exe` — скоро (CI) |
| 🤖 **Android** | [`KRYLAN-android-debug.apk`](https://github.com/Alex1986-rgb/CleanMac/releases/latest/download/KRYLAN-android-debug.apk) |
| 📱 **iPhone/iPad** | сборка через Xcode / Sideloadly с вашим Apple ID (подпись 7 дней) |

**Лендинг:** https://alex1986-rgb.github.io/CleanMac/

**Homebrew** (каск прямо из репозитория):
```bash
brew install --cask https://raw.githubusercontent.com/Alex1986-rgb/CleanMac/main/Casks/cleanmac.rb
```

**Готовый `.dmg`** — перетащите CleanMac в «Программы».

> ### ⚠️ Первый запуск: «Apple не удалось подтвердить, что файл не содержит вредоносного ПО»
> Сборка пока **не нотаризована** (нужен платный Apple Developer ID — см.
> [«Почему не в App Store»](#почему-не-в-app-store)). Файл, скачанный из интернета,
> получает метку карантина, и macOS отказывается его запускать.
>
> **На macOS 15 Sequoia и новее совет «ПКМ → Открыть» больше не работает** — Apple убрала
> этот обход. Рабочих способа два:
>
> 1. Одной командой в Терминале — снять метку карантина:
>    ```bash
>    xattr -dr com.apple.quarantine /Applications/CleanMac.app
>    ```
> 2. Или: запустить, получить отказ, затем **Системные настройки → Конфиденциальность
>    и безопасность** → внизу «Всё равно открыть».
>
> Если этого не сделать, приложение не просто не откроется — ядро прибивает процесс
> сигналом 9 сразу при запуске, без окна и без сообщения в логах.

> Сборка **universal2** (Intel + Apple Silicon) — работает на всех маках с macOS 11+.

**Из исходников** (карантина нет, Gatekeeper не мешает):
```bash
git clone https://github.com/Alex1986-rgb/CleanMac.git
cd CleanMac
python3 CleanMac.py
```
> Нужен Python 3.9+ с tkinter — годится и системный `/usr/bin/python3` из Command Line
> Tools. Внешних зависимостей у приложения нет; Pillow требуется только для пересборки
> иконки (`make_icon.py`).

## Почему не в App Store?

Системные чистильщики **не проходят** в Mac App Store: песочница MAS запрещает
доступ к кэшам других приложений, `pmset`/`system_profiler` и завершение чужих
процессов. Поэтому CleanMac, как CCleaner и CleanMyMac, распространяется
**нотаризованным .dmg** напрямую.

## Безопасность

- Любое удаление = перемещение в **Корзину** / «Недавно удалённые» / корзину с undo (можно вернуть).
- Кэш браузера не трогается, пока браузер запущен.
- Никаких сетевых отправок данных; единственный сетевой запрос — проверка версии на GitHub.
- Никакой чистки реестра, дефрага SSD, fake-booster и страшилок — только честные операции.
