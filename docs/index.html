🛡️ Почему KRYLAN безопаснее конкурентов

Наше УТП — только обратимое и честное. Никаких трюков, которыми грешат агрессивные «бустеры».

❌ Без чистки реестра

CCleaner, BoostSpeed и Glary чистят реестр «для скорости» — и ломают Windows. Мы этого не делаем.

❌ Без дефрага SSD

Дефрагментация SSD не ускоряет, а изнашивает накопитель. KRYLAN дефрагментирует только магнитные HDD.

❌ Без фейк-бустеров

Никаких «RAM boost» и «ускорим в 10 раз» (как Boost Cleaner, 1Tap). Только реальная разгрузка памяти.

❌ Без страшилок

Никаких «storage full!» ради тапа. Честные локальные уведомления — как требуют политики App Store и Google Play.

✅ Только обратимое

Любое удаление — в Корзину, «Недавно удалённые» или корзину с undo. Передумали — вернули.

✅ Честные цифры в ГБ

Реальные гигабайты и превью «что и сколько освободится» до очистки. Системное под защитой — решаете вы.

С кем сравниваем: CleanMyMac / DaisyDisk (mac) · CCleaner / BoostSpeed / BleachBit / Stacer (desktop) · Gemini / Smart Cleaner (iOS) · SD Maid / Files by Google (Android). Мощнее — но бесплатно, с открытым кодом и без вреда.

📸 Скриншоты — на всех устройствах

Тёмная тема, фирменный глобус, единая кнопка «✨ Оптимизировать» — Desktop, iPhone и Android.

✨ Оптимизировать — умная кнопка для любого устройства

Одна кнопка ✨ «Оптимизировать» делает РАЗНОЕ на разных устройствах. KRYLAN сам определяет ОС (Windows / macOS / Linux) и тип диска (SSD или HDD) и подбирает только то, что на этом железе безопасно и полезно. SSD-дефраг, например, изнашивает накопитель — поэтому KRYLAN его никогда не делает.

Дополнительно только на macOS: удаление снимков APFS, перестройка Launch Services, сброс Dock. Права: команды с админ/root KRYLAN пытается выполнить сам; при отказе — пропуск с пометкой, без запроса пароля. После прохода приложение само показывает «Выполнено» и «Пропущено на этом устройстве».
Только безопасное. Кнопка не трогает реестр, не делает SSD-дефраг, не отключает службы и не чистит Корзину автоматически. Пользовательские данные (дубли, крупные и старые файлы) кнопка только показывает — разбираете их вы вручную. 🪽 Дай устройству крылья — но без вреда.

📖 Установка и использование

Пошагово для каждого устройства. macOS 2.48.0 · Desktop 1.18.0.

macOS — CleanMac

  1. Скачайте CleanMac.dmg со страницы Releases.
  2. Откройте .dmg и перетащите CleanMac в «Программы».
  3. Первый запуск: ПКМ по иконке → «Открыть» → «Открыть» (приложение вне App Store, без подписи — это разовое действие).
  4. Альтернатива — Homebrew:
brew install --cask https://raw.githubusercontent.com/Alex1986-rgb/CleanMac/main/Casks/cleanmac.rb

Требования: macOS 11+, Apple Silicon или Intel (universal).

Windows — KRYLAN Desktop

  1. Скачайте KRYLAN-Windows.exe со страницы Releases.
  2. Если SmartScreen предупреждает: «Подробнее» → «Выполнить в любом случае» (сборка без платной подписи).
  3. Запустите — Python уже внутри, ничего ставить не нужно.

Linux — KRYLAN Desktop

  1. Скачайте KRYLAN-linux-x86_64 со страницы Releases.
  2. Дайте права и запустите:
chmod +x KRYLAN-linux-x86_64
./KRYLAN-linux-x86_64

tcl/tk включены в сборку. Если в системе нет tkinter: sudo apt install python3-tk.

iPhone / iPad — KRYLAN (beta)

  1. Скачайте .ipa со страницы Releases.
  2. Установите через бесплатный AltStore или Sideloadly с вашим Apple ID.
  3. Подпись бесплатного Apple ID живёт 7 дней — потом переустановить. App Store / TestFlight — позже.

Android — KRYLAN

  1. Скачайте .apk со страницы Releases.
  2. Разрешите «Установка из этого источника».
  3. Откройте файл → «Установить». (Для Google Play в релизе есть и .aab.)
Как пользоваться: нажмите ✨ «Оптимизировать» — один клик делает всё безопасное именно для вашего устройства (кэши и временные файлы, на SSD — TRIM, на HDD — дефрагментация и т.д.); приложение само показывает «Выполнено / Пропущено». Всё удаление обратимо (Корзина / «Недавно удалённые»). Пользовательские данные (дубли, крупные и старые файлы) приложение только показывает — разбираете вы вручную. Вопросы и ответы

Это безопасно? Да. Всё удаление — в Корзину (обратимо). Системные и корневые папки защищены. Кэш браузера чистится только когда браузер закрыт.
Бесплатно? Да, с открытым кодом (MIT). Без рекламы и сбора данных.
Почему Gatekeeper/SmartScreen предупреждает? Сборки пока без платной подписи разработчика. Первый запуск: macOS — ПКМ → «Открыть»; Windows — «Подробнее» → «Выполнить».
Чистите ли вы реестр / дефрагментируете? Нет — это вредно (реестр-клинеры ломают Windows, дефраг изнашивает SSD). Мы делаем только безопасные операции.
Почему не в App Store? Системные оптимизаторы не проходят песочницу Mac App Store — поэтому CleanMac, как CCleaner и CleanMyMac, распространяется напрямую (нотаризованный .dmg / Homebrew). Universal-сборка работает на Intel и Apple Silicon. Первый запуск без подписи: ПКМ → «Открыть».
